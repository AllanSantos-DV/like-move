Segurança

Acordado só onde você confia

Deixar a tela bloquear é uma defesa. Num café ou aeroporto, manter a máquina acordada é convite para acesso indevido. O like-move reconhece a rede pelo nome e pelo endereço do ponto de acesso — então uma rede falsa com o mesmo nome não engana o app.

  • ✓SSID + BSSID. Casa o nome da rede com o MAC do access point — resiste a ataques evil-twin.
  • ✓Um clique. "Marcar rede atual como confiável" lê o Wi-Fi conectado e adiciona à lista.
  • ✓Cabo configurável. Sem Wi-Fi (Ethernet), você decide se conta como confiável.
  • ✓Qualquer outra rede deixa a tela bloquear normalmente. Segurança por padrão.

Como funciona

Win32 puro, do jeito certo

Cada capacidade mapeada para a API nativa que a implementa — sem pywin32, sem netsh.

GetLastInputInfo
Tempo desde o último input real (mouse/teclado) para medir inatividade.
OpenInputDesktop
Detecta tela bloqueada (Secure Desktop) — evita jiggle inútil.
SendInput
Move o cursor +1px e volta: imperceptível, reseta o timer de inatividade.
WM_DEVICECHANGE
Detecção de KVM orientada a evento — janela oculta recebe as trocas de dispositivo.
WlanQueryInterface
Lê SSID + BSSID da rede atual para o gate de redes confiáveis.
GitHub Releases API
Verifica a versão mais nova e baixa o novo .exe para o auto-update.
