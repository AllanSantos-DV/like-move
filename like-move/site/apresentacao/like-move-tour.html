like-move: a tela não bloqueia, só quando você quer

Windows · grátis · código aberto

Esta é uma apresentação rápida do programa: para que serve, para quem é, como se usa e por que ele é seguro.

Para Windows

A tela não bloqueia no meio da conversa

O like-move mantém o Windows sem bloquear por inatividade, só quando você quer e só nas redes em que você confia.

Para quem é

Reuniões por voz

Você fala e ouve, mas não mexe no computador.

Quem usa KVM

O teclado e o mouse foram para outro PC e este fica parado.

Leitura e acompanhamento

Um painel, um documento longo, um processo rodando.

Você escolhe quando

Inatividade

Depois de 15 segundos a 5 minutos parado.

KVM

Quando monitor, mouse ou teclado saem.

Ambos

Qualquer uma das duas condições.

Sempre

Enquanto estiver ativo.

Seguro fora de casa

Redes confiáveis

Marque o Wi-Fi de casa pelo nome e pelo ponto de acesso. Uma rede falsa com o mesmo nome não é aceita.

Fora delas, bloqueia

No café ou no aeroporto o Windows bloqueia normalmente.

Fechou, voltou ao normal

Ele não muda nenhuma configuração do Windows. Sem o programa aberto, tudo fica como antes.

Como usar

  1. Baixe e extraia

    Baixe o like-move-win64.zip e extraia numa pasta sua.

  2. Abra o like-move

    O ícone verde aparece na bandeja do sistema.

  3. Escolha o modo

    Clique direito no ícone: modo, tempo, redes confiáveis.

  4. Se quiser, com o Windows

    Marque Iniciar com Windows; não precisa de administrador.

Como funciona por dentro
Em vez de mexer o mouse, o like-move pede ao Windows para manter a tela e o sistema ligados, o mesmo recurso que players de vídeo usam. Quando você fecha o programa, o Windows desfaz o pedido sozinho.
